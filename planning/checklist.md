# Exhibition Checklist

## Before Exhibition
- [ ] تعیین هدف فروش و لید
- [ ] تعیین بودجه
- [ ] نهایی‌کردن مفهوم غرفه
- [ ] تعیین محصولات و نمونه‌ها
- [ ] آماده‌سازی قیمت‌نامه و پیشنهاد B2B
- [ ] آماده‌سازی فرم/سیستم ثبت لید
- [ ] تعیین مسئولیت اعضای تیم
- [ ] آماده‌سازی اقلام تبلیغاتی
- [ ] برنامه‌ریزی دعوت مشتریان هدف

## During Exhibition
- [ ] ثبت تمام لیدها
- [ ] qualification لیدها
- [ ] ثبت اقدام بعدی برای هر لید
- [ ] پایش KPI روزانه
- [ ] ثبت بازخورد مشتریان

## After Exhibition
- [ ] پاک‌سازی و دسته‌بندی لیدها
- [ ] تماس با لیدهای اولویت‌دار
- [ ] ارسال پیشنهادها
- [ ] زمان‌بندی follow-up
- [ ] گزارش KPI
- [ ] محاسبه هزینه و بازده
- [ ] ثبت درس‌آموخته‌ها
