# Project Management Data

این پوشه محل نگهداری داده‌های اصلی و نسخه‌بندی‌شده مدیریت پروژه است.

## اصل اصلی
CSV منبع اصلی داده‌های ساختاریافته مدیریت پروژه است. Excel و Google Sheets در صورت استفاده، برای مدیریت، تحلیل و نمایش داده‌ها هستند.

## قواعد
- داده‌های واقعی پروژه در CSV ثبت شوند.
- تاریخ‌ها با فرمت `YYYY-MM-DD` باشند.
- شناسه‌های استاندارد پروژه حفظ شوند.
- وضعیت‌ها استاندارد و ثابت بمانند.
- تغییرات مهم با Commit معنادار ثبت شوند.
- قبل از هر overwrite در صورت اختلاف CSV و فایل مدیریتی، اختلاف بررسی شود.
- بعد از هر Freeze، اطلاعات مرتبط با نسخه فریز‌شده سینک شود.
- اطلاعات محرمانه، Token، Secret، Password و داده حساس مشتریان وارد CSVها نشود.
- داده‌ای که مشخص نشده است حدس زده نشود.

ساختار و ستون‌های هر CSV باید بر اساس داده و تصمیم واقعی پروژه تکمیل شوند؛ این فایل صرفاً قواعد نگهداری داده را مشخص می‌کند و جایگزین داده‌های پروژه نیست.
